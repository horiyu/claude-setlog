# 実装上の注意

Android Emulator、setlog、Claude Codeについて、実装中に確認した挙動をまとめます。

## 画面の向きとカメラ映像

- setlogは横向きでのみ撮影できます。`adb emu sensor set acceleration -9.81:0:0`で加速度センサーを変更し、`0:9.81:0.8`で元に戻します。
- 横向きでは、Logは正立したままソース上端の16:9領域（1710x962）を使用します。ソース動画は1710x1280で、4:3のカメラ映像として扱われます。
- setlogはカメラセッションを開いた時点の動画を使用します。動画を差し替えた後はsetlogを開き直します。
- インカメラは鏡像になるため、背面カメラを使用します。

## 投稿とアップロード

- 「sent」は投稿直後に表示されますが、動画はその後アップロードされます。投稿処理は、150 KB以上送信された後、9秒間通信が静かになるまで待機します。上限は約3分です。
- 動画再生中はUI Automatorで画面を取得できないため、投稿画面には固定座標を使用します。
- 投稿画面を開いた時点でキャプション欄にフォーカスがあります。

## Claude Codeの会話ログ

- thinkingは暗号化されるため、指示、応答、ツール呼び出しなど平文の内容だけを表示します。
